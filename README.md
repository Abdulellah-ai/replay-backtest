# Replay Backtest

Manual historical replay (backtest) app for gold (XAUUSD and XAUEUR). For education and personal practice only. Not financial advice; past data does not predict the future. No price data is included in this repo.

## تشغيل التطبيق (ويندوز)

1. ثبّت **Node.js** (نسخة LTS) من https://nodejs.org و**Python 3** من https://www.python.org (فعّل خيار Add to PATH).
2. نزّل المشروع: زر **Code** ثم **Download ZIP** في صفحة المستودع، وفك الضغط.
3. اضغط مرتين على `get-data.bat`. ينزّل المكتبات وبيانات الذهب (مرة واحدة فقط، يحتاج إنترنت وقد يأخذ عدة دقائق).
4. اضغط مرتين على `start.bat`. يفتح التطبيق في المتصفح على `http://localhost:8770/index.html`. أبقِ نافذته السوداء مفتوحة أثناء الاستخدام.

## Run it (Windows)

1. Install **Node.js** (LTS) and **Python 3** (tick "Add to PATH").
2. Download the repo as ZIP and unzip it.
3. Double-click `get-data.bat` once (installs packages and downloads the gold data).
4. Double-click `start.bat` and keep its window open while you use the app.

## التشغيل

تحتاج Python. انقر مرتين على `start.bat`، واترك نافذة Server مفتوحة. للإيقاف اضغط `Ctrl+C` فيها. إذا فتح المتصفح قبل جاهزية Server، حدّث الصفحة.

أو شغّل من مجلد المشروع:

```text
python -m http.server 8770 --directory .
```

ثم افتح `http://localhost:8770/index.html`.

بعد أي تحديث اضغط `Ctrl+Shift+R`.

## الأدوات

| الأداة | الاستخدام |
|---|---|
| Play / Pause | تشغيل Replay أو إيقافه مؤقتًا. |
| Speed | اختيار 1 أو 5 أو 20 أو 60 صف M1 في الثانية كسرعة مستهدفة. |
| Step M1 | التقدّم صف M1 واحدًا من البيانات المتاحة. |
| Step bar | إكمال شمعة XAUUSD الحالية، أو التالية إذا كانت الحالية مكتملة، حسب Timeframe. |
| Jump | اختيار تاريخ عند 00:00 UTC ضمن البيانات؛ ينتقل إلى آخر صف متاح عنده أو قبله. |
| Sync crosshair | إظهار مؤشر مقابل في الشاشة الأخرى حسب الوقت. |
| Sync scroll | مزامنة التمرير والتكبير عندما تغطي البيانات المحمّلة الفترة المطلوبة. |
| Sync timeframe | تغيير Timeframe للشاشتين معًا؛ عطّله لاختيار كل شاشة وحدها. |
| Session H/L | مدّ أعلى وأدنى ASIA وLNDN وNYAM وNYPM بعد اكتمالها حتى تجاوز السعر للمستوى؛ الملامسة وحدها لا توقف الخط. |
| Kill zones | تشغيل الجلسات وتعديل أوقاتها حسب America/New_York. |
| Timeframe لكل شاشة | اختيار 1m أو 5m أو 15m أو 1h أو 4h أو 1D. |
| MA50 | إظهار أو إخفاء المتوسط البسيط لـ50 شمعة في الشاشة. |
| Trend + 3 colours | رسم خط بنقطتين؛ الأبيض والأصفر والأزرق للرسم التالي أو الخط المحدد. |
| Rect + 3 colours | رسم مستطيل بنقطتين وتعديل حجمه بالمقابض؛ الأبيض والأخضر والذهبي للرسم التالي أو المستطيل المحدد. |
| Fib | رسم Fibonacci بنقطتين؛ مستوى 0 عند النقطة الثانية. |
| Fib presets | اختيار مجموعة المستويات للرسومات الجديدة. |
| Fib levels | إضافة مجموعات المستويات وتعديلها وحذفها، ثم Save. |
| Long | رسم أداة شراء بثلاث نقاط: Entry ثم Stop ثم Target، وعرض Risk/Reward. |
| Short | رسم أداة بيع بثلاث نقاط: Entry ثم Stop ثم Target، وعرض Risk/Reward. |
| Magnet | تشغيل أو إيقاف جذب نقاط الرسم إلى OHLC القريب؛ مشترك بين الشاشتين. |
| Clear | حذف رسومات أدوات الرسم في الشاشة نفسها. |
| Divider | سحب الفاصل لتغيير عرض الشاشتين. |

`Delete` أو `Backspace`: حذف الرسم المحدد فقط. أثناء رسم Trend، اضغط `Shift` لجعله أفقيًا أو عموديًا حسب اتجاه الماوس الأقرب. انقر مرتين على Trend أو Rect لكتابة نص، ثم Save.

## البيانات

الأسعار تُحمَّل بـ `get-data.bat` إلى `data/*.json` (غير مرفقة في المستودع): بيانات Dukascopy، بسعر bid ودقة M1، من 2026-03-08 إلى 2026-11-06. الإعدادات، ومنها Kill zones وFib presets، تُحفظ في `localStorage` بالمتصفح. التشغيل يقرأ الملفات المحلية؛ تحديث الأسعار يحتاج Node.js واعتماديات المشروع و`npm run fetch` ويستخدم الشبكة. مثال لكل رمز:

```text
npm run fetch -- XAUUSD 2026-03-08 2026-11-07
npm run fetch -- XAUEUR 2026-03-08 2026-11-07
```

## الحدود المعروفة والتحقق

- توجد فجوات بيانات، وبعض أسبابها غير مؤكدة؛ يظهر تنبيه للفجوات المصنفة unexplained في الفترة المعروضة.
- RSI يُحسب على البيانات المحمّلة؛ قد تختلف قيم البداية عن حساب كامل التاريخ.
- Sync scroll لا يحرّك الشاشة الأخرى إذا لم تغطِّ بياناتها المحمّلة كامل الفترة؛ لا يحمّل الفترة المطلوبة تلقائيًا.
- تفعيل Session H/L أول مرة، والرجوع للخلف أو تغيير الجلسات، يعيد فحص التاريخ المكشوف. قياسات Node لا تثبت سرعة المتصفح.
- أسماء الجلسات تُخفى عند ضيق المساحة أو التداخل.
- نص الرسم محدود بـ40؛ حقل المتصفح قد يقبل 20 emoji فقط. قد تُحسب نهاية جلسة مخصصة عند أول ظهور للوقت المتكرر في نهاية DST.
- Long وShort للرسم والحساب فقط؛ لا تنفيذ صفقات ولا حساب PnL. لا يوجد VWAP؛ معنى volume غير مؤكد، وترخيص مصدر البيانات لهذا الاستخدام لم يُتحقق منه.

لم يُتحقق بعد من: `Shift` بمفتاح فعلي، وجذب Magnet إلى high/low/close، ومطابقة Kill zones وFib وشمعة NY17 اليومية مع TradingView، وFPS الفعلي أثناء Play.
